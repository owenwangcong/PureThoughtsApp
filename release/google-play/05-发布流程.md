# Google ⑤ 发布流程(封测 → 正式)

## 1. 先确认你的开发者账号类型 ⚠️ 这决定要不要跑 14 天封测

| 账号类型 | 是否需要封闭测试 |
|---|---|
| **个人开发者账号**(2023-11 之后新建) | **必须**:先做封闭测试,**≥12 名测试员连续 14 天**保持加入状态,期间要有真实使用,之后才能申请正式发布 |
| **组织/公司账号**(有 D-U-N-S 号) | **不需要**,可直接提交正式发布 |

个人账号的这条要求是硬门槛,提前**两周**开始准备招测试员——共修团体里找 12 位同修最省事,
每人一个 Google 账号,加入后**这 14 天里不要退出**,并请他们真的打开用一用(低活跃度会被
判定不达标,要重来)。

## 2. 应用签名

| 项 | 现状 |
|---|---|
| 签名方式 | Play App Signing(上传密钥 + Google 保管发布密钥) |
| 上传密钥 | 在 `app/android/keys/`(**不入库,务必已备份**);Codemagic 端以 `purethoughts_upload` 引用 |
| 构建产物 | AAB(`flutter build appbundle --release`,见 `codemagic.yaml`) |

> 上传密钥丢了 = 无法再更新这个 App(只能重新上架一个新包名)。确认已经有异地备份。

## 3. 建立发布轨道

```
Test and release → Testing → Closed testing → 新建 release
```

| 字段 | 填什么 |
|---|---|
| Release name | `1.0.0 (1)` |
| App bundle | Codemagic 产出的 `app-release.aab`(或用 codemagic.yaml 里的自动发布到 Play) |
| Release notes(zh-TW / zh-CN) | 用 `../shared/文案库.md` §6 的首版说明 |
| Testers | 建一个 Email list,把 12+ 位测试员邮箱加进去,并把 opt-in 链接发给他们 |

## 4. 封测期间要完成的事

- [ ] `01-app-content.md` 的十项任务全部通过(隐私政策、App access、Ads、分级、目标受众、Data safety、Government、Financial、Health、类别与联系方式)
- [ ] `02-store-listing.md` 的文案与素材上传完毕
- [ ] 测试员反馈的问题修完并发新版本到封测轨道(允许多次更新,14 天计时**不会**因发新版重置,但测试员必须持续在册)
- [ ] 生产推送实测:海外 Android 收到 FCM 推送;大陆 Android 用 App 内通知中心兜底

## 5. 申请正式发布

封测满 14 天且人数达标后:

```
Dashboard → 「Apply for production access」→ 填一份问卷
```

问卷会问:测试期间学到什么、做了哪些改进、目标用户是谁、如何获取用户。据实写(几百字),
描述共修团体的实际场景与封测反馈即可。审核通常 几天 内出结果。

通过后:`Production → Create new release` → 上传同一个 AAB → 分阶段发布(建议先 20%,
观察崩溃率再放到 100%)。

## 6. 上线后

- [ ] Play Console → **Monitor and improve → Android vitals** 看崩溃率与 ANR
- [ ] 把 Play 链接补进 `../README.md` 与官网
- [ ] Sentry 里确认有真实设备的上报流入

## 7. 常见卡点

| 卡点 | 说明 |
|---|---|
| Data safety 未填 | 所有轨道(含封测)都必须填完才能发布 |
| 隐私政策 URL 打不开 / 要登录 | 直接驳回,发布前自己用无痕窗口验证一次 |
| 测试员不足 12 或中途退出 | 14 天要重新计;宁可拉 15 人留余量 |
| target SDK 过低 | **2026-08-31 起必须 target Android 16(API 36)**,否则不能发布更新。Flutter 3.32 的 `flutter.targetSdkVersion` 仍是 35,已在 `android/app/build.gradle.kts` 显式写死 `targetSdk = 36`(compileSdk 本来就是 36)。改完要**重新出 AAB 并上传**,Policy status 里的告警才会消失 |
| 权限用途未说明 | 相机/麦克风(Webex 会议)、开机自启与电池优化豁免(定时提醒)——若 Play 追问,按 `../apple/04-app-review-information.md` 的 Notes 内容回答即可 |
