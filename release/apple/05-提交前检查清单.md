# Apple ⑤ 提交前检查清单

按顺序打勾,全绿再点 Submit for Review。

## A. 提交前必须先有的东西

- [ ] 隐私政策网页已上线且公网可访问(`../shared/隐私政策.md` → 官网)
- [ ] Support URL 页面已上线(至少有联系邮箱)
- [ ] 生产环境已建好 `appreview` 演示账号,并**实测能登录**、各页面有内容
- [ ] 决定 iPad:改 `TARGETED_DEVICE_FAMILY = "1"` 仅 iPhone(推荐),或补 13" iPad 截图

## B. 构建

- [ ] `app/pubspec.yaml` 版本 = `1.0.0+1`
- [ ] Codemagic 构建用的 `--dart-define` 指向**生产** `https://api.pure-thoughts.com` 与生产 anon key
- [ ] Sentry DSN 已配置(否则崩溃无从追查)
- [ ] APNs 推送证书/密钥在 Apple Developer 后台配好,生产环境推送实测收到
- [ ] TestFlight 自测:登录 → 报数 → 统计 → 通知 → 删除账号流程全部走通
- [ ] 真机走查大字号(200%)与深色模式无错版

## C. App Store Connect 填写

- [ ] App Information:名称/副标题/类别/Content Rights(`01-app-information.md`)
- [ ] Age Rating 问卷已答完(注意 2026 新增的社交与 wellness 题)
- [ ] Pricing:Free,销售范围已选(中国大陆区**不选**,无 ICP 备案)
- [ ] App Privacy:数据类型与隐私政策一致,Tracking = No(`03-app-privacy.md`)
- [ ] 版本页:截图 8 张(繁/简各一套)、描述、关键词、Promotional Text、Copyright
- [ ] App Review Information:演示账号 + 备注整段粘贴(`04-app-review-information.md`)
- [ ] Version Release:Manually release

## D. 送审后

- [ ] 关注邮件与 Resolution Center;被拒不要重复提交,先按拒审理由逐条回复
- [ ] 通过后手动放行上线,再在共修团体内发通知
- [ ] 上线后把 App Store 链接补进 `README.md` 和官网

## E. 已知的两个裁量点(被问到时怎么答)

1. **Unrestricted Web Access**:答 No。理由——WebView 只加载固定的经本站点与 Webex
   会议室,无地址栏、无任意浏览入口。若审核坚持,改 Yes 并接受更高分级。
2. **社交动态流**:答 No。理由——共修记录列表无点赞/评论/转发/关注,不做排名,
   不构成"再分发或放大 UGC"。若审核坚持,改 Yes,分级变 13+ 并显示 Social Media 标签,
   功能无需改动。
