## 1. 截图 App Previews and Screenshots

**iPhone 只需传一组尺寸**,Apple 会自动缩放到其它机型。⚠️ **上传前先确认页面上那个槽是哪一档**
—— ASC 的截图区按显示尺寸分组(iPhone 6.9" / 6.5" / …),尺寸对不上会直接报
「The dimensions of one or more screenshots are wrong」。两档素材都已备好:

| 槽位 | 要求尺寸 | 用哪个目录 |
|---|---|---|
| **iPhone 6.9" Display** | 1290×2796(或 1320×2868 / 1260×2736) | `release/screenshots/apple/6.9-1290x2796/{zh-Hant,zh-Hans}/` |
| **iPhone 6.5" Display**(ASC 常默认展示这一档) | 1284×2778(或 1242×2688) | `release/screenshots/apple/6.5-1284x2778/{zh-Hant,zh-Hans}/` |

切换槽位:截图区右上角 **View All Sizes in Media Manager**,在里面挑 6.9" 或 6.5" 再拖文件。
两档任传一档即可满足要求;如果想两档都填满,素材也都在。

## 3. Build

| 项 | 值 |
|---|---|
| 版本号 / Build | `1.0.0` / `1`(`app/pubspec.yaml` 的 `version: 1.0.0+1`) |
| 出包方式 | Codemagic(`codemagic.yaml`),**不在本机做 release 构建** |
| 上传后 | 先进 TestFlight 自测,再在版本页选中该 build |

出包前确认 `--dart-define` 指向**生产** Supabase(`https://api.pure-thoughts.com`)与生产 anon key,
不要把本地栈地址打进 release 包。

## 4. 加密合规(App Uses Non-Exempt Encryption)

`app/ios/Runner/Info.plist` 已声明:

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

→ 上传后 **不会**再弹加密问卷;App 只用 HTTPS 与系统标准加密,属于豁免类。无需提交
年度自分类报告(不出口受管制加密)。
