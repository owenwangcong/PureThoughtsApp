## 3. Build

| 项 | 值 |
|---|---|
| 版本号 / Build | `1.0.0` / `1`(`app/pubspec.yaml` 的 `version: 1.0.0+1`) |
| 出包方式 | Codemagic(`codemagic.yaml`),**不在本机做 release 构建** |
| 上传后 | 先进 TestFlight 自测,再在版本页选中该 build |

出包前确认 `--dart-define` 指向**生产** Supabase(`https://api.pure-thoughts.com`)与生产 anon key,
不要把本地栈地址打进 release 包。

## 4. 加密合规(App Uses Non-Exempt Encryption)

`app/ios/Runner/Info.plist` 已声明:

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

→ 上传后 **不会**再弹加密问卷;App 只用 HTTPS 与系统标准加密,属于豁免类。无需提交
年度自分类报告(不出口受管制加密)。
